# ERP Agro

Sistema multiplataforma de gestão logística e compras agrícolas — **MVP visual mock** (v0.0.1).

## Demonstração

```bash
flutter pub get
flutter run -d chrome
```

## Cadastros (Admin / Gestora)

No menu **Cadastros**:

1. Aba **Grupos** → **Criar grupo**
2. Aba **Produtos** → **Cadastrar produto**
3. Aba **Clientes** → **Cadastrar cliente** (associar ao grupo)

Há também botões no topo: Novo grupo · Novo produto · Novo cliente.
